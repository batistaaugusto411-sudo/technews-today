# 📱 TechNews Today - Portal de Notícias Tech

Este repositório contém o desenvolvimento do portal de notícias **TechNews Today**, uma página web moderna em tema escuro (*dark mode*) criada com **HTML5 Semântico** e **CSS3 Avançado**, sem o uso de frameworks ou JavaScript.

---

## 🚀 Tecnologias e Conceitos Utilizados

* **HTML5 Semântico:** Estruturação limpa e acessível com tags como `<header>`, `<main>`, `<article>`, `<section>`, `<details>`, `<summary>`, `<iframe>` e `<footer>`.
* **CSS3 Moderno:**
  * **Glassmorphism:** Efeito de vidro fosco no cabeçalho usando `backdrop-filter: blur(10px)`.
  * **Texto em Degradê:** Efeito de gradiente no logo com `background-clip: text`.
  * **Layout em CSS Grid:** Organização responsiva dos cards e elementos da página.
  * **Header Fixo (Sticky):** Navegação fixa no topo durante a rolagem com `position: sticky`.
  * **Responsividade:** Ajuste de layout para telas móbiles e desktops utilizando `@media` queries.

---

## 📋 Checklist do Desafio Atendido

- [x] **Glassmorphism:** Efeito de transparência desfocada no cabeçalho.
- [x] **Gradiente no Texto:** Título da logo com transição de cores vibrantes.
- [x] **CSS Grid:** Alinhamento modular entre os artigos, vídeo e formulário.
- [x] **Position Sticky:** Cabeçalho fixado no topo da página.
- [x] **Media Query:** Layout adaptado de 1 coluna (Mobile) para 2 colunas (Desktop).
- [x] **Pure CSS:** Nenhuma biblioteca externa ou arquivo de JavaScript utilizado.
